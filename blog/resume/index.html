代表專案

SAP RFC 網關與 Agent 整合基礎｜2026/11

  • 建立 sapFDE 整合環境，以 uv 管理 Python 3.11、PyRFC 與 SAP SDK 載入設定。
  • 整合開源 sap-for-agents v0.19.0，建立安裝、啟動及驗證 launcher；完成 RFC 登入、ping、網關就緒與呼叫回傳驗證。
  • 探索指定範圍內 603 筆 RFC／BAPI 與 55 個自訂透明表，取得訂單交接表欄位定義及資料樣本。
  • 診斷舊 SAP 缺少 RFC_READ_TABLE 參數的相容性問題，改用通用 RFC 介面成功查詢。

成果為整合與查詢驗證；網關核心來自開源專案，自動相容降級及業務寫入流程仍待開發／驗證。專案成果
